ОПИСАНИЕ ПРОЕКТА
В данном проекте реализована программа вывода содержимого файлов в 
шестнадцатеричном виде (hexdump). Программа поддерживает различные 
опции командной строки для настройки формата вывода, включая 
смещение, размер кусочков, количество кусочков в строке и 
пользовательскую форматную строку.

Структура проекта:
- lib/ - библиотека с реализацией функций hexdump
- app/ - основное приложение
- tests/ - модульные и интеграционные тесты

ТРЕБОВАНИЯ
- CMake 3.15 или выше
- Компилятор C (GCC/Clang)
- MSYS2 (для Windows) или Linux/macOS

СБОРКА ПРОЕКТА В MSYS2
1. Откройте терминал MSYS2 (MINGW64)
2. Перейдите в директорию проекта:
   > cd /путь/к/проекту/Task_2_2

3. Создайте директорию сборки и перейдите в неё:
   > mkdir build
   > cd build

4. Запустите конфигурацию CMake:
   > cmake -G "MinGW Makefiles" ..
   
   Для сборки с динамической библиотекой:
   > cmake -G "MinGW Makefiles" -DBUILD_SHARED_LIBS=ON ..

5. Соберите проект:
   > cmake --build . --config Debug
   или
   > cmake --build . --config Release

6. Запустите программу:
   > ./app/my_program.exe -i ../test.bin

СБОРКА ПРОЕКТА В VS CODE
1. Установите необходимые расширения VS Code:
   - CMake Tools (ms-vscode.cmake-tools)
   - C/C++ (ms-vscode.cpptools)
   - CMake (twxs.cmake)

2. Откройте папку проекта в VS Code

3. VS Code автоматически обнаружит CMake проект.
   В нижней панели появится кнопка "Configure"

4. Выберите компилятор: MinGW Makefiles

5. Для сборки нажмите:
   - Ctrl+Shift+P → CMake: Build
   или
   - Ctrl+Shift+B (сборка по умолчанию)

6. Для запуска программы:
   - Ctrl+Shift+P → CMake: Debug Target / Launch Target
   или
   - F5 (если настроена отладка)

7. Альтернативно, используйте встроенный терминал:
   > mkdir build && cd build
   > cmake -G "MinGW Makefiles" ..
   > cmake --build . --config Debug
   > ./app/my_program.exe -i ../test.bin

ИСПОЛЬЗОВАНИЕ ПРОГРАММЫ
Базовый вывод файла:
   > ./app/my_program.exe -i test.bin

Вывод со смещением:
   > ./app/my_program.exe -i test.bin -o 10

Вывод с ограничением размера:
   > ./app/my_program.exe -i test.bin -l 100

Вывод с размером кусочка:
   > ./app/my_program.exe -i test.bin -g 4

Вывод с количеством кусочков в строке:
   > ./app/my_program.exe -i test.bin -n 8

Вывод всех файлов в директории:
   > ./app/my_program.exe -d ./folder

Вывод с форматной строкой (оценка 4):
   > ./app/my_program.exe -i test.bin -f "%i %n %0x %1x | %0c%1c\n"

ЗАДАНИЕ
2.2. Программа вывода содержимого файлов в шестнадцатеричном виде.

Условия для оценки 3.
Программа должна поддерживать опции командной строки (передаются в любом порядке):
- -i file_name — имя выводимого файла
- -o offset — смещение от начала файла, с которого выводится содержимое (если не задано, то выводить с начала файла)
- -l size — количество выводимых из файла байт (если не задано, то выводить всё)
- -g size — размер кусочка (если не задано, то 1)
- -n count — количество кусочков, выводимых в одной строке (если не задано, то 16)
- -d dir — директория, из которой выводить файлы

Если задана директория, то выводить все файлы в директории.

В каждой строке программа должна выводить смещение от начала файла, указанное количество кусочков информации в шестнадцатеричном виде. Если кусочек равен байту (т.е. опция -g 1), то в конце строки после вывода данных в шестнадцатеричном виде выводить их же в символьном виде (для каких это возможно).

Осуществлять преобразование байт файла в шестнадцатеричные символы самостоятельно. Т.е. с помощью printf можно выводить только символы (с помощью %c), соответствующие байтам содержимого файла (которые необходимо самостоятельно перевести в символы). Смещение можно выводить с помощью printf в виде числа (через %x).

Для разбора аргументов командной строки использовать функцию getopt. Настроенный шаблон для задания прилагается (template(2)).

Пример использования.
Пусть содержимое файла file (последовательность байт в шестнадцатеричном виде):
0x10 0x11 0x12 0x13 0xFA 0xFB 0xFC 0xFD 0x00 0x20 0x30 0x40 0x41 0x42 0x31 0x32 … 0xAB12

./prog -i file
00000000  10 11 12 13 FA FB FC FD 00 20 30 40 41 42 31 32  |........0@AB12|
00000010  33 34                                           |34|

./prog -i file -o 3 -l 8 -g 3
00000003  FBFA13 00FDFC 003020

./prog -o 2 -g 4 -n 2 -l 12 -i file
00000002  FBFA1312 2000FDFC
0000000A  42414030

./prog -o 2 -l 11 -g 4 -n 2 -i file
00000002  FBFA1312 2000FDFC
0000000A  00414030

Условия для оценки 4.
Дополнительно поддерживать опцию:
- -f format_str — указание форматной строки, определяющей формат вывода каждой строки.

Форматная строка состоит из обычных символов, специсимволов и спецификаторов.
Обычными символами считаются все символы, которые не являются специсимволами или частью спецификатора.
Специсимволами являются символы \ и %, которые меняют интерпретацию следующего за ними символа. Поддерживать следующие последовательности:
- \n — байт перевода строки (0x0A)
- \r — байт возврата каретки (0x0D)
- \t — байт табуляции (0x09)
- \\ — символ \

Спецификаторы соответствуют выводимым кусочкам (их количество в строке и размер задаётся параметрами -n, -g) файла.
Спецификаторы имеют вид:
- %i — индекс текущей строки
- %n — смещение текущей строки
- %x — вывод i-го кусочка в шестнадцатеричном виде (1, 2 или 4 символа в зависимости от размера кусочка)

./prog -i file -f "%i %n %0x %1x %2x %3x %4x %5x %6x %7x %8x %9x %10x %11x %12x %13x %14x %15x |"
0 00000000 10 11 12 13 FA FB FC FD 00 20 30 40 41 42 31 32 | ........0@AB12
1 00000010 33 34                                           |34|

./prog -i file -o 2 -g 2 -n 3 -f "%i x0 = %x0 = %x0\t\tx1 = %x1\tx2 = %x2(%2c)\n"
0 x0 = 1312    x2 = FDFC(..)
1 x0 = 2000    x2 = 4241(AB)
2 x0 = 3231    x2 = 0000(..)
